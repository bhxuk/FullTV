# FullTV Changelog

## [0.1.0] — 2026-10-23
### Added
- Initial Windows desktop preview with dark TV-inspired homepage.
- ADB package discovery, connection, APK installation, launch and uninstall.
- Plex web quick-launch and preference persistence.
- GitHub release update checker with SHA-256 validation of installer assets.
- Windows CI release/installer pipeline and GitHub Pages landing page.

### Not yet implemented
- Bundled Android virtual machine, video/audio bridge and native GPU acceleration.
- Proven playback of Android streaming APKs, integrated Plex Android playback or 4K decoding.
- Full controller input, production-grade themes and automatic silent updates.

This is an early development preview, not a production Android TV emulator.
