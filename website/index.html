Get started

From Windows to FullTV.

01 / INSTALL

Install FullTV

Download the Windows installer from GitHub Releases. The desktop application is published as a self-contained build.

02 / CONNECT

Connect Android

For APK management, install platform-tools and authorise ADB on your existing Android device or emulator.

03 / ENJOY

Make it yours

Open your apps, launch Plex, adjust your accent colour and check for new FullTV versions.

Before installing

System requirements.

Operating systemWindows 10 or Windows 11 (x64)
Windows installerSelf-contained .NET desktop application
Android app managementAndroid platform-tools / ADB plus an authorised device or emulator
UpdatesInternet access to GitHub Releases
Development preview: FullTV does not currently include an Android operating system or run APK files independently. It cannot guarantee 4K playback or support for every Android streaming application. We show these limitations rather than advertise unfinished features as working.
